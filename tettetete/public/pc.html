Scanne ce code avec l'appareil photo de l'iPhone.

Dossier de réception
L'iPhone n'arrive pas à se connecter ?
  • Le PC et l'iPhone doivent être sur le même réseau Wi-Fi.
  • Au premier lancement, Windows demande d'autoriser Node.js : accepte. Si tu as refusé, lance ceci dans un terminal administrateur :
  • Sur un réseau d'entreprise, d'école ou « invité », les appareils sont souvent isolés les uns des autres. Active le partage de connexion de l'iPhone, connecte le PC dessus, relance Swipe et rescanne le code.
  • Si le PC change de réseau, son adresse change : rescanne le code et recrée l'icône sur l'écran d'accueil.
